# Algorithm Practice

A historical set of C and C++ algorithm exercises, organized by original study day rather than invented problem identifiers.

```text
practice/c/       C exercises (day01–day08 and the original additional source)
practice/cpp/     C++ exercises (day09–day16)
include/          Shared historical headers
legacy/windows/  A separate incomplete MFC dialog fragment
docs/            Original filenames and validation
```

Select one exercise and inspect it before building. Several files include problem statements as plain text, multiple entry points, legacy-encoded comments, or platform-specific code. This is a practice archive, not one compilable application or a verified complete solution set.

When needed, include the shared headers with `-I include`. The Windows fragment depends on files absent from this repository and is kept outside the algorithm exercises.

No problem numbers, acceptance rates, performance results, or solution correctness claims were inferred. See [source index](docs/catalog.md) and [validation](docs/validation.md).
